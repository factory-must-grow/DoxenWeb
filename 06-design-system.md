# 06 — Дизайн-система

Эталон — `doxen-design.html`. Этот документ фиксирует правила, чтобы
новые экраны не разъезжались с макетом.

## Идея

Главный приём — **маркер**. Жёлтая подсветка означает ровно одно:
«здесь пусто, это нужно заполнить». Она работает одинаково везде:
в герое главной подсвечены `{{...}}`, в предпросмотре — незаполненные
места, и жёлтой же кнопкой отмечено главное действие экрана.

Из этого следует правило: **жёлтый не используется больше нигде.**
Ни для акцентов, ни для ссылок, ни для декора. На экране максимум одна
жёлтая кнопка. Всё остальное — чернильно-синий, серый и белая бумага.

## Токены

```css
:root{
  --paper:#FFFFFF;        /* бумага документа, фон панелей */
  --ink:#14213D;          /* основной текст, кнопки, границы в фокусе */
  --muted:#5C6B84;        /* вторичный текст, подписи */
  --rule:#DDE3EC;         /* линейки, границы */
  --marker:#FFE066;       /* маркер: незаполненное + главное действие */
  --marker-deep:#F0C808;  /* граница и наведение для жёлтой кнопки */
  --surface:#F4F6FA;      /* фон страницы */
}
```

`--ink` — насыщенный синий, а не подкрашенный чёрный. Не заменять его
на `#111` или `#0B0B0B`.

Переопределения Bootstrap задаются через его же CSS-переменные
(`--bs-primary`, `--bs-body-color`, `--bs-border-color`), а не правкой
классов `.btn-primary` и подобных.

## Шрифты

- **Golos Text** — весь интерфейс. Русская гарнитура, спроектированная
  под кириллицу; для юридического сервиса на `.ru` уместнее
  международных Inter/Roboto.
- **JetBrains Mono** — только пути и переменные (`org.bank.bankName`).
  Моноширинный здесь несёт смысл: переменная — это код, а не текст.
  Не использовать его для подписей, чисел и меток.

Подключение — Google Fonts с `display=swap` и `preconnect`.

Шкала: `h1` — `clamp(2.1rem, 4.4vw, 3.4rem)`, вес 700, `letter-spacing:-.025em`.
Основной текст — 0.9375rem. Подписи — 0.8125rem. Длина строки в
абзацах — не больше 34em (`.lead-sm` в макете).

## Компоненты

**`.sheet`** — лист документа. Белый фон, тонкая рамка, скругление 3px,
двойная тень (близкая жёсткая + дальняя мягкая). Используется для
предпросмотра и демо. Не применять к обычным панелям.

**`.panel`** — рабочая панель. Белый фон, рамка `--rule`, скругление 4px,
**без тени**. Панели не выглядят как карточки — граница вместо тени.

**`.tok`** — переменная под маркером. Жёлтый фон плюс `box-shadow`
той же толщины по краям, чтобы подсветка выходила за границы текста
как настоящий маркер.

**Кнопки** — три вида, скругление 3px:
- `.btn-marker` — главное действие, одна на экран
- `.btn-ink` — обычное действие
- `.btn-quiet` — второстепенное, прозрачная с рамкой

**Строки формы** разделены линейками `--rule`, а не помещены в
отдельные карточки. Над полем — подпись, под ней путь переменной
моноширинным шрифтом.

## Чего не делать

Эти приёмы намеренно отсутствуют в макете:

- градиентные заливки и цветные фоны секций
- одинаковые скруглённые карточки с мягкой серой тенью
- заглавные буквы для меток и надзаголовков
- нумерация вроде `01 / 02 / 03` там, где содержимое не является
  последовательностью (в «Как это работает» она уместна — там шаги)
- стрелки `→` в тексте кнопок и ссылок
- анимации появления при прокрутке на каждом блоке

## Движение

На весь сайт — **одна** анимация: в герое главной подсвеченные
переменные один раз заменяются значениями. Она показывает суть продукта
вместо того, чтобы её описывать.

Всё остальное движение — только ответ на действие пользователя
(раскрытие, подтверждение, загрузка).

Обязательно уважать `prefers-reduced-motion: reduce` — при нём
анимация в герое не запускается вовсе, значения показываются сразу.

## Доступность

Проверять на каждом экране:

- видимый фокус клавиатуры (`:focus-visible` с обводкой `--ink`)
- контраст текста не ниже 4.5:1 — `--muted` на `--paper` проходит,
  `--muted` на `--surface` на грани, не использовать его там для
  мелкого текста
- жёлтый маркер несёт смысл «не заполнено», поэтому это состояние
  должно дублироваться текстом («осталось заполнить 6 значений»), а не
  только цветом
- у полей ввода настоящие `<label for>`, а не подписи-`<div>`
- поля дат: и выбор в календаре, и ручной ввод с клавиатуры
